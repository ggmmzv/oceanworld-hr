# OceanWorld HR System

Система учета кадров для организации "Мир океана"

## Функциональность

- 📊 Генерация тестовых данных (960+ записей)
- 📁 Экспорт в Excel, HTML, PHP, XML
- 🎨 Красивый веб-интерфейс с CSS
- 🔄 Автоматизированный CI/CD

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/ТвоеИмя/oceanworld-hr.git

# Активация виртуального окружения
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python main.py
